# Privacy Policy

**Effective date:** September 5, 2026

Code Input EN does not collect, transmit, sell, or share personal data.

The app observes foreground application changes locally so it can recognize supported coding applications. It does not record this activity or send it anywhere. The selected keyboard layout and app preferences are stored only on the user's Mac using `UserDefaults`.

Code Input EN contains no networking, advertising, analytics, telemetry, crash-reporting service, or third-party runtime code.

Questions about this policy can be submitted through the repository's [GitHub Issues](https://github.com/alexeyvax/code-input-en/issues).
